Yeet OS runs Catch as a system service. Use `catch version` to check the installed daemon and `sudo yeet-os upgrade` to update the host.

## Usage

```bash
catch [flags] [install|version|is-catch]
```

## Commands

- `install`: install catch as a system service on the host.
- `version`: print the installed Catch build version. Any local user can run this command, even before Catch has a data directory.
- `is-catch`: print `yes` for detection.

## Common flags

- `--data-dir`: base directory for catch state. Installed catch uses the data
  directory selected during install. Manual runs default to `/var/lib/yeet`.
- `--services-root`: default root for service directories. The default service
  root is `<data-dir>/services`, which is `/var/lib/yeet/services` with the
  default data directory.
- `--tsnet-host`: catch Tailscale hostname. Default: `catch`.
- `--tsnet-port`: catch RPC port on its Tailscale identity.

See [Data Layout](/docs/concepts/data-layout) for host storage and
[Tailscale](/docs/concepts/tailscale) for Tailscale setup.

## When to run catch directly

Use direct catch invocation only when you are installing manually, checking the
catch version on the host, or debugging catch startup. If the goal is to deploy
or operate services, use the `yeet` command path so local config, host
targeting, and auth behavior stay in the normal loop.

Use [Host Setup](/docs/getting-started/host-setup) for the supported
bootstrap path and [yeet Commands](/docs/cli/yeet-cli) for normal operations.
